# 四脚小球风格化造型能力特训网络班（第三期）

获课：jzit.top/26896/

**一、班级定位：用一个极简对象，练一套通用的造型方法**

四脚小球这个题材看似简单 —— 一个球形的身体加四条腿 —— 但它恰恰是风格化造型最好的练手对象：结构信息少，任何一处比例、剪影或色彩上的犹豫都藏不住。第三期的功能定位正在这里：它的目标已经超出 “把这个小东西画好看”，更在于借这个对象，把风格化造型的判断方法建立起来，再迁移到角色、道具、IP 形象等更复杂的题材上。

**二、形状语言功能：让轮廓自己说话**

风格化造型的第一项功能是形状语言的运用。圆形传递亲和与柔软，方形传递稳定与可靠，三角形传递危险与速度。训练班要练的首要能力，就是先决定这个角色要说哪句话，再决定用什么形状去说。四脚小球天然偏圆，因此课程的重点反而在于 “如何在不破坏圆润基调的前提下加入对比”—— 腿的粗细、足部的方正感、耳朵或角的锐度，都是微调性格的杠杆。功能目标是：只看纯黑剪影，也能读出角色的性格与类型。

**三、比例与夸张功能：夸张要夸张在关键处**

第二项功能是比例控制与有目的的夸张。风格化的本质是有选择的变形，并非整体缩小。课程会训练一套判断顺序：先确定视觉焦点（是眼睛、是头部、还是身体的整体态），再把夸张资源集中投在这个焦点上，其余部分保持克制。常见的新手错误是处处夸张，结果画面没有主次。功能目标是画面有一处让人记住的地方，而不是平均用力。

**四、体块归纳与结构功能：简化不等于糊掉**

第三项功能是体块归纳。风格化造型要减少信息，但不能丢失结构逻辑：球体作为主体，四肢如何连接、关节如何暗示、重心在哪里、能不能站住。课程通常要求学员用最少的体块把这个小东西概括出来，并做多角度推演，确认它在侧视、俯视、仰视下都不 “塌”。功能目标是简而不空：观者不看细节也相信它是个立得住的东西。

**五、面部与表情功能：亲和力的生成机制**

第四项功能是面部与表情。风格化角色的性格有大量由面部承担：眼距决定气质，瞳孔大小影响可爱度，嘴角与眉眼的角度决定情绪倾向。训练班会把表情当作独立模块来练：同一形体下做出数种情绪版本，检验形体是否具备承载表演的空间。功能目标是小角色具备 “可被喜欢” 的稳定表情语言。

**六、色彩与材质功能：把复杂表面压成几块**

第五项功能是色彩与材质简化。风格化的上色追求 “色块清晰、明度秩序明确”，而非写实的反射细节。课程会训练主色、辅色、点缀色的配比关系，以及通过明度差而非细节堆叠来塑造体积。材质上则强调区分 “这是什么质感” 的少量关键特征 —— 皮革的柔、金属的硬 —— 只保留必要暗示。功能目标是缩小尺寸、降低精度之后，角色依然辨识度极高。

**七、动态与姿态功能：让造型进入使用场景**

第六项功能是动态适配。四脚小球最终要出现在游戏、动画、盲盒、表情包里，静止造型如果一动就变形或崩掉，就不能算完成。课程会安排基础姿态测试：行走、蹲伏、跳跃、回头等，检验造型在动态中的可读性，并反推修改。功能目标是角色在运动状态下仍保持性格与剪影的一致性。

**八、系列化与延展功能：从单件到一套**

第七项功能是系列化能力。真实项目往往要求基于同一个形象产出多个变体：换配色、换配件、换体型、换情绪。训练班会让学员在既定造型规范下做延展，检验其造型语言是否足够稳固、可复制。功能目标是建立一套 “可被他人沿用” 的造型规范，这是走向 IP 与商业落地的前提。

**九、呈现与反馈机制功能**

第八项功能是呈现与迭代。三视图、转面、渲染展示、版式组织，决定作品能否被看懂；高频批改与横向对比，决定进步速度。第三期的特色在于把反馈做得可指认：问题出在剪影、比例、结构还是色彩，逐条对齐，避免 “再改改” 这类模糊评价。

**十、结语**

以功能视角看这门特训班，它用一个极小对象承载了一套完整方法：定性格、控剪影、管比例、稳结构、做表情、压色彩、验动态、能延展。学员真正要带走的是这套判断顺序，而非某一只小球；换个题材它依然管用，这才是风格化造型能力的实质。
